# Parte II - Métodos não supervisionados de reconhecimento de padrões

**Arquivos para demonstração - Parte II - Métodos não supervisonados de reconhecimento de padrões**

Nesta pasta os usuários tem acesso aos arquivos de demonstração prática utilizando a interface de “Análise Exploratória” com estudos reais retirados da literatura:

(1) discriminando vinhos de diferentes regiões vinícolas italianas denominadas por Análise de Componentes Principais (PCA);

(2) discriminando espécies de flores Iris por dados de quatro características taxonômicas medidas por Mapas Auto-Organizáveis (SOM);

(3) agrupando amostras de soja pela localização geográfica do cultivo de acordo com a composição inorgânica por Análise de Agrupamentos por Métodos Hierárquicos (HCA);

(4) agrupando amostras de leite comercial de acordo com o teor de gordura utilizando dados espectrais adquiridos em um espectrômetro NIR portátil por k-means;

(5) explorando a estabilidade oxidativa de óleos usando por análise multibloco/multitabela com o método de Análise por Dimensões Comuns (ComDim);

(6) Comparando formulações de cervejas artesanais por estatística descritiva de grupos.
